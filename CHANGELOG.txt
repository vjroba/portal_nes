PortalNES 更新履歴
==================

Version 0.8
-----------

- 通常のUnityカメラで立体表示を確認できる3Dシーンを追加しました。
- 3Dシーンのカメラ背景色を、ゲームの背景色へリアルタイムに同期するようにしました。
- 視点操作用のTransformMouseControllerをInput Systemに対応させました。
- 数字キーの1と2で、3DカメラのFOVを調整できるようにしました。
- ROM選択画面、F3プロファイル編集画面、Portalgraph設定画面以外では、
  マウスカーソルを自動的に非表示にするようにしました。
- Portalgraph SDKを含まない形でソースコードを公開できる構成を用意しました。


Version 0.7
-----------

- F3プロファイル編集画面の形状選択を、実用性のある
  Flat、Box、Pixelsの3種類に整理しました。
- 背景Pixel Extrusionで、正面のDepth、側面の長さ（Thickness）、
  押し出さない色が残るRear / Base Depthを個別に設定できるようにしました。
  立体部分の奥端と背景面の間に空間を設けられます。


Version 0.6
-----------

- 対応Mapperを追加しました。

  Mapper 5、32、33、48、65、70、71、78、80、97

- Mapper 5（MMC5）のPRG/CHRバンク切り替え、拡張Nametable、
  Vertical Split、Scanline IRQおよび拡張音源に対応しました。
- Portalgraphランタイムを更新しました。
- 3Dスプライトの画像とOAM座標が異なるフレームを参照する問題を修正しました。
  高速で移動する弾などの表示と、F3プロファイル編集画面の選択枠が
  実際の描画位置に一致するようになりました。
- スプライトのフレーム同期改善に伴い、補助的な1フレーム残像表示を廃止しました。


Version 0.5
-----------

- プロファイルのルール数が増えた際の速度低下を改善しました。
- クイックセーブ／クイックロードが失敗することがある問題を修正しました。
- Xbox系コントローラーのLBにクイックセーブ、RBにクイックロードを
  割り当てました。
- 左スティックを十字キーと同じ移動操作に対応させました。


Version 0.4
-----------

- 一般的なNES 2.0形式のROMヘッダーに対応しました。
- 古いROMダンプに見られるDiskDudeヘッダーの誤判定を補正しました。
- Mapper 3のバスコンフリクトとNES 2.0 Submapperの差異に対応しました。
- PPUCTRLによる遅いNMI有効化のタイミングを改善しました。
- フレーム追いつき処理中は最新フレームだけを3D描画するようにし、
  処理落ちから復帰しやすくしました。
- シェーダー版Pixel ExtrusionがPortalgraphの視点移動へ
  常に追従するように改善しました。
- F3のプロファイル編集画面をドラッグしている間は、
  Portalgraphの視点をマウス操作しないようにしました。
- 背景タイルの着色ピクセル数による自動Depth判定を廃止しました。
  未設定の背景タイルは同じDepthとなり、プロファイルの
  デフォルト設定または個別ルールだけで奥行きが変化します。
- 高速な弾や点滅するスプライトを見やすくする、
  1フレームのスプライト残像表示を追加しました。
- ゲーム内の操作ガイドとROM読み込みエラー画面を英語化しました。


Version 0.3
-----------

- Xbox系コントローラーのボタン割り当てを、ボタン名ではなく
  NESコントローラーの物理配置に合わせて変更しました。

  Bボタン（右） : NES A
  Aボタン（下） : NES B
  Yボタン（上） : 連射A
  Xボタン（左） : 連射B


Version 0.2
-----------

- 対応Mapperを大幅に追加しました。

  Mapper 9、10、18、19、
  21、22、23、24、25、26、
  67、68、69、72、73、75、76、
  85、86、87、88、89、93、95、
  140、154、184、206、210

- Mapper 19（Namco N163）、24/26（Konami VRC6）、
  69（Sunsoft 5B）、85（Konami VRC7）の拡張音源に対応しました。
- セーブステート機能を追加しました。

  F6 : ステートを保存
  F7 : ステートを読み込み

- CHR ROMバンクおよびCHR RAMを使用するゲーム向けに、
  タイル内容によるプロファイル照合を改善しました。


Version 0.1
-----------

- ファーストリリース。
- Mapper 0、1、2、3、4、7、66に対応しました。
- NES背景タイルとスプライトのリアルタイム3D表示に対応しました。
- Portalgraphでの多視点表示に対応しました。
- タイルごとのDepth、形状、厚みを設定できる
  立体化プロファイル編集機能を搭載しました。
